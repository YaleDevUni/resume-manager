# Resume Manager for HR

A powerful application designed to streamline resume management and candidate tracking for technical recruiting.

## Quick Start

Website Link:
[Resume Manager](https://resume.yesyeil.ca/)

For local deployment:
1. Navigate to `local-deploy-docker`
2. Download and run `build.sh` from the root directory

## Overview

Resume Manager for HR is a comprehensive solution for organizing and evaluating technical candidates. The application excels at handling large volumes of applications, supporting bulk uploads of up to 100 resumes simultaneously. HR professionals can efficiently track recruitment progress, manage application documents, and evaluate candidates through a user-friendly interface.

## Core Features

### Advanced Resume Organization
- Bulk upload capability for up to 100 resumes
- Intelligent document management system
- PDF preview and annotation functionality
- Comprehensive candidate status tracking

### Powerful Search and Filtering
- Skill-based filtering
- Candidate rating system
- Application status tracking
- Advanced search capabilities across all documents
- Multi-parameter filtering for precise candidate selection

### Recruitment Campaign Management
- Dedicated recruitment drive organization
- Status tracking across hiring stages
- Document association with specific campaigns
- Performance metrics and insights

## Technology Stack

### Frontend
- React for dynamic user interface
- Redux for state management
- Modern responsive design

### Backend
- Express.js server
- Passport authentication system
- MongoDB database
- Secure file handling
